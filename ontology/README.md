# Ontology layer

This directory records the project's evolving model of its subject matter. It is a navigation and reasoning aid, not a claim of completeness or objective correctness.

- `glossary.md` records important terms and competing definitions.
- `concepts.md` records conceptual entities worth tracking.
- `relationships.md` records explicit, provisional relationships.

Every entry should be revisable and traceable to research where appropriate.

This project uses an ontology to organize research, but it also studies “ontology” as a philosophical, aesthetic, and computational term. The organizing structure must never be mistaken for evidence that those senses are equivalent. Record bridges among them as hypotheses in `relationships.md` until sources justify stronger language.
