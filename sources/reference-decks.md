# Reference decks

A reference deck is a curated, ordered view of sources for a question, article, or recurring research theme. It does not duplicate source material and does not change catalog acceptance status.

## Future deck template

Create `decks/NNN-short-name.md` containing:

- the bounded question;
- related articles with direct links;
- anchor and companion sources by stable source ID;
- why each source is present;
- a reading order;
- access and preservation constraints;
- a selection board for writer decisions; and
- gaps that require new source discovery.

One source may appear in many decks. Keep its metadata and preserved original in one place.
