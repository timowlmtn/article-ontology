# Source library inventory

This inventory mirrors the source identities in `research/source-catalog.md` while tracking local preservation separately. The catalog remains authoritative for status and metadata.

For curated reading sequences and quick links, see `reference-decks.md`.

## Status vocabulary

- **External only:** catalog link exists; no source material is stored locally.
- **Source record:** a local README preserves identity and access information, but not the original media.
- **Local original:** original source bytes are stored without modification.
- **Transcript pending:** audiovisual source is identified, but captions/transcript have not been captured and verified.
